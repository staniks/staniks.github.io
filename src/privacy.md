As a static website, this Site does not directly collect, store, or process personal data from its visitors.

This Site is hosted using GitHub Pages. Because of this, GitHub may collect certain "Log Data," which includes, but is not limited to:

- Your IP address.
- Your browser type and version.
- The pages you visit on this site.
- The time and date of your visit.

This data is used by GitHub for security purposes and to keep the service running. For more details, please consult the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

- These external services are governed by their own respective privacy policies.
